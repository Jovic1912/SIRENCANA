      ✓ Nama + bobot persen
      ✓ Validasi total bobot = 100% sebelum diajukan
      
      Route:
      - POST /rps/{id}/jenis/add (filter: role:dosen,admin)

      ✓ Bobot per sel (0-100)
      ✓ Update batch (RpsController::updateMatriks)
      ✓ Insert jika bobot > 0, delete jika bobot = 0

      - POST /rps/{id}/matriks (filter: role:dosen,admin)

      Kolom: id, rps_id, jenis_penilaian_id, cpmk_id, bobot

   e. ALUR PERSETUJUAN RPS (WORKFLOW)
      ✓ 6 aksi transisi status dengan log otomatis:
      
      1) AJUKAN (draft/revisi_diperlukan → diajukan)
         - Hanya pengembang RPS
         - Validasi total bobot jenis penilaian = 100%
         - Route: POST /rps/{id}/workflow/ajukan (filter: role:dosen,admin)
         - Method: RpsController::wfAjukan
      
      2) REVISI (diajukan → revisi_diperlukan)
         - Hanya GKM
         - Catatan wajib diisi
         - Route: POST /rps/{id}/workflow/revisi (filter: role:gkm)
         - Method: RpsController::wfRevisi
      
      3) SETUJU (diajukan → disetujui_gkm)
         - Hanya GKM
         - Route: POST /rps/{id}/workflow/setuju (filter: role:gkm)
         - Method: RpsController::wfSetuju
      
      4) TTD DOSEN (disetujui_gkm → ttd_dosen flag = 1)
         - Hanya dosen pengembang atau kaprodi (jika kaprodi = dosen)
         - Set flag ttd_dosen = 1
         - Route: POST /rps/{id}/workflow/ttd-dosen (filter: role:dosen,kaprodi)
         - Method: RpsController::wfTtdDosen
      
      5) TTD KAPRODI (disetujui_gkm → ttd_kaprodi flag = 1)
         - Hanya kaprodi yang ditetapkan di rps.koor_prodi_id
         - Set flag ttd_kaprodi = 1
         - Route: POST /rps/{id}/workflow/ttd-kaprodi (filter: role:kaprodi)
         - Method: RpsController::wfTtdKaprodi
         
         Auto-transisi: jika ttd_dosen=1 DAN ttd_kaprodi=1 → status = 
         ditandatangani
      
      6) ARSIP (ditandatangani → diarsipkan)
         - Hanya GPM atau kaprodi
         - Input lokasi arsip fisik (opsional)
         - Set flag arsip_gpm = 1
         - Route: POST /rps/{id}/workflow/arsip (filter: role:gpm,kaprodi)
         - Method: RpsController::wfArsip
      
      Tabel: rps_status_log
      Kolom: id, rps_id, status, catatan, oleh (nama + role), tanggal
      
      Status yang ada:
      - draft
      - diajukan
      - revisi_diperlukan
      - disetujui_gkm
      - ditandatangani
      - diarsipkan

   f. VISIBILITAS RPS

      ✓ Admin & kaprodi: semua RPS
      ✓ GKM & GPM: RPS dengan status != draft

7. LAPORAN & ANALISIS OBE
────────────────────────────────────────────────────────────────────────────
   ✓ Controller: CapaianController, PortofolioController

   a. CAPAIAN CPMK & CPL
      ✓ Laporan per kelas (CapaianController::show)
      ✓ Hitung capaian CPMK otomatis dari nilai × matriks penilaian
      ✓ Method: CapaianController::hitung() - shared dengan portofolio
      
      Kalkulasi:
      - Nilai per CPMK = weighted average dari semua jenis penilaian yang 
        berkontribusi ke CPMK tersebut (via matriks_penilaian)
      - Skala rubrik: ≥80 = Sangat Baik, ≥65 = Baik, ≥50 = Cukup, <50 = Kurang
      - Lulus CPMK: nilai ≥ 65
      - Nilai akhir mahasiswa = weighted average dari semua jenis penilaian
      - Konversi huruf: A (≥85), A- (≥80), B+ (≥75), B (≥70), B- (≥65), 
        C+ (≥60), C (≥55), D (≥40), E (<40)
      - Rekap presensi: H/I/S/A count + skor kehadiran (%)
      - Eligible: skor kehadiran ≥ 75%
      
      Helper functions di obe_helper.php:
      - rekap_presensi()
      - nilai_akhir()
      - capaian_cpmk()
      - nilai_huruf()
      - skala_rubrik()
      
      Route:
      - GET /capaian (filter: auth)
      - GET /capaian/{kelas_id} (filter: auth, validasi kepemilikan)
      
      Output:
      - Tabel per mahasiswa: NIM, nama, presensi, nilai akhir, nilai per CPMK
      - Summary per CPMK: total mahasiswa, count per skala (SB/B/C/K), 
        persentase lulus

   b. PORTOFOLIO KELAS
